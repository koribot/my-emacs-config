* ⌨  Keys
#+BEGIN_EXAMPLE
  ── Navigation ──────────────────────────────────────────
  C-Tab / C-S-Tab    next / prev buffer or window

  C-x C-f            find file
  C-x 2 / 3          split horizontal / vertical

  ── Ivy / Minibuffer ────────────────────────────────────

* 📦  Packages
#+BEGIN_EXAMPLE

* 🐙  Magit  (Git)
#+BEGIN_EXAMPLE
  C-x g               open magit  (main entry point)
  M-x magit-status    same as above

  ── Staging (git add) ───────────────────────────────────
  s        stage file or hunk under cursor   (git add file)
  S        stage all                         (git add .)
  u        unstage                           (git restore --staged)
  U        unstage all
  TAB      expand file to see individual hunks
           then s/u on a specific hunk to stage/unstage just that

  ── Committing ──────────────────────────────────────────
  c c      commit  → write message → C-c C-c confirm, C-c C-k cancel
  c a      amend last commit  (edit message or add more changes)
  c w      reword last commit  (only change the message)

  ── Remote ──────────────────────────────────────────────
  P p      push                             (git push)
  F p      pull                             (git pull)

  ── Branches ────────────────────────────────────────────
  b b      switch branch                    (git checkout)
  b c      create and switch branch         (git checkout -b)

  ── Other ───────────────────────────────────────────────
  l l      log / history
  d d      diff file under cursor
  z z      stash                            (git stash)
  z p      stash pop                        (git stash pop)
  q        quit / go back

  ── Undo ────────────────────────────────────────────────
  k        discard file/hunk changes        (git restore, CANNOT undo)
  K        discard all unstaged
  x        soft reset  (in log, on a commit) (git reset --soft)
           → uncommits but keeps changes staged
  X        hard reset  (in log, on a commit) (git reset --hard)
           → WARNING: discards all changes permanently
  V        revert commit  (in log, creates new undo commit, safe)

  ── Common Scenarios ────────────────────────────────────
  Undo last commit, keep changes    l l → on last commit → x
  Fix last commit message           c w  or  c a
  Throw away file changes           k on the file
  Committed to wrong branch         l l → x → b c → commit again
#+END_EXAMPLE
